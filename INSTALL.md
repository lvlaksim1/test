# Инструкция по использованию «Циклического времени»

## Перед началом

Приложение работает **через Shizuku** и не требует root, ADB-команд в приложении или включения специальных возможностей. Перед первым запуском установите Shizuku, запустите его службу стандартным способом Shizuku и оставьте приложение открытым во время серии циклов.

## Первый запуск

| Шаг | Действие |
|---|---|
| 1 | Установите APK и откройте приложение. |
| 2 | Установите и запустите приложение **Shizuku**. |
| 3 | В «Циклическом времени» нажмите строку **Shizuku** и подтвердите доступ. |
| 4 | Убедитесь, что строка показывает **«Shizuku: доступ выдан»**. |
| 5 | При необходимости включите системную синхронизацию времени переключателем в приложении. При запуске цикла она будет выключена автоматически. |

## Настройка цикла

Укажите стартовую дату и время в формате `ДД.ММ.ГГГГ` и `ЧЧ:ММ`, затем шаг изменения в днях, часах и минутах. Для шага допускаются отрицательные значения. Задайте паузу в секундах и количество циклов. Первая попытка использует стартовую дату/время; каждое следующее значение рассчитывается с указанным шагом.

Общий крупный контрол **«− / +»** находится между разделами «Старт» и «Шаг изменения». Он меняет последнее поле, в которое был установлен курсор. Пустое числовое поле рассматривается как ноль. Пауза между успешными изменениями отсчитывается монотонными системными часами, поэтому не сокращается из-за задержки применения времени или обновления интерфейса.

Во время цикла приложение обновляет поля «Старт» каждым успешно установленным значением. Для немедленной остановки используйте красную кнопку внизу экрана.
