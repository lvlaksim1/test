# Машина времени

Android-приложение для последовательного изменения системной даты и времени через Shizuku.

## Возможности

- стартовая дата и время, включая заполнение по кнопке «Сейчас»;
- шаг изменения в днях, часах и минутах, в том числе отрицательный;
- вложенный цикл с собственной паузой и количеством повторов;
- главный цикл с отдельной паузой между сериями;
- сохранение и загрузка именованных конфигураций шага и повторения;
- фоновое выполнение через foreground service;
- локальный журнал действий с копированием и очисткой;
- светлая и тёмная темы Android.

Приложение не использует аккаунт, сервер или облачное хранилище. Пользовательские параметры и конфигурации хранятся локально на устройстве.

## Сборка

Релизный APK собирается GitHub Actions. Рабочие ветки `work-*` только собирают проверочный APK; тег и GitHub Release создаются исключительно из `main`.

Перед Android-сборкой CI выполняет тесты, TypeScript-проверку и ESLint.
